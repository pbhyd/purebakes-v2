# Wedding domain SEO strategy

Status: decision document only. Phase 4 does not change `weddingcakeshyderabad.in`, redirects, DNS or cross-domain canonicals.

## Current overlap risk

PureBakes owns `weddingcakeshyderabad.in` for wedding-focused search visibility. The existing PureBakes path `/luxury-wedding-cakes-hyderabad/` historically declared a cross-domain canonical, while Search Console evidence also shows legacy wedding URLs and meaningful demand for Hyderabad wedding cake queries. Publishing substantially identical wedding pages on both domains could divide relevance signals or create unclear canonical selection.

## Phase 4 treatment

The PureBakes legacy URL is preserved as a useful, self-contained portfolio and navigation page because the Phase 4 brief requires existing PureBakes URLs to remain available. It uses real PureBakes engagement/wedding inventory and clearly belongs to the broader studio experience. No redirect or cross-domain canonical decision is made.

## Differentiation options

1. Keep PureBakes focused on the studio portfolio, enquiry flow and relationship between wedding, engagement and anniversary work. Position the wedding domain as an editorial planning resource with deeper tiering, venue-handling and wedding-specific guidance.
2. Consolidate wedding authority on one domain after comparing complete Search Console landing-page/query data, backlinks and content quality. This would require an approved redirect and canonical migration plan.
3. Maintain both only if each has a distinct audience and purpose. Avoid duplicated titles, body copy, FAQs and image selections; document which domain owns each query cluster.

## Internal linking

Natural branded links may connect the sites when they help customers—for example, PureBakes could link to a genuinely deeper wedding planning guide, and the wedding domain could identify PureBakes as the studio. Cross-links should not become sitewide exact-match SEO links.

## Recommendation

Defer consolidation until both properties have comparable 16-month Search Console exports, backlink evidence and a content inventory. Then choose one explicit model and test its effect. Until that review, preserve both properties, differentiate content, avoid automatic canonical changes and make no production redirects.
