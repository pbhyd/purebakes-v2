# PureBakes V2

Mobile-first Eleventy foundation for the PureBakes premium custom cake studio website.

```bash
npm install
npm run dev
npm test
npm run build:production
```

`npm run build` creates protected staging output for `new.purebakes.in`. Production output is configuration-driven and must not be deployed until all migration gates are approved. See `docs/phase-2-implementation.md` and the Phase 1–1.7 audit artifacts before changing URLs or content architecture.
